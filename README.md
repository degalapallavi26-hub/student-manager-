# Student Management System

## About the Project
A Python-based Student Management System to manage student records easily.

## Features
- Add Student Details
- View All Students
- Search Student by ID
- Update Student Details
- Delete Student Records
- Save Student Data in JSON Format

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python.
2. Download the project file.
3. Open the terminal.
4. Run the following command:

python "student manager.py"
